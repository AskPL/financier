# Как собрать и установить собственный APK «Финансист 1.6»

В этой версии проект полностью подготовлен как для классического запуска через **Simple HTTP Server (`localhost`)**, так и для сборки в нативное Android-приложение (`.apk`) на базе **Capacitor 6**.

---

## Способ 1. Сборка APK за 2 минуты через GitHub (БЕЗ установки Android Studio на ПК)

Если не хочется скачивать 10 ГБ Android Studio на компьютер, бесплатный облачный сервер GitHub соберёт `.apk` сам:

1. Создайте бесплатный приватный (Private) репозиторий на [GitHub](https://github.com/new) и загрузите туда все файлы из этого архива (включая папку `.github/workflows/build-apk.yml`).
2. Откройте вкладку **Actions** в вашем репозитории → выберите **«Сборка Android APK (Финансист 1.6)»** → нажмите **Run workflow**.
3. Через ~2 минуты внизу страницы сборки появится блок **Artifacts → `Financier-1.6-Android-APK`**.
4. Скачайте архив, достаньте `app-debug.apk`, отправьте его на телефон (например, через Telegram) и установите!

### Как перенести свои данные из браузера в новый APK:
1. В старой браузерной версии: **Ещё → Настройки → Скачать копию** (или **📤 Отправить копию**).
2. В установленном APK: **Ещё → Настройки → Восстановить** и выберите сохранённый `.json` файл.

---

## Способ 2. Локальная сборка на компьютере (Windows)

1. Установите [Node.js LTS](https://nodejs.org/) и [Android Studio](https://developer.android.com/studio).
2. Дважды кликните по файлу **`build-apk.bat`** в папке проекта.
3. Скрипт сам создаст папку `www`, подключит Android-ядро Capacitor и откроет проект в Android Studio.
4. В верхнем меню Android Studio выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

---

## Способ 3. Продолжить запуск через Simple HTTP Server (`localhost`)

Все веб-файлы (`index.html`, `app.js`, `sw.js` и таблицы стилей) по-прежнему лежат прямо в корне архива:
* Достаточно распаковать архив в прежнюю папку телефона и один раз обновить страницу через Simple HTTP Server — все новые функции (новый пульт Курьерки, создание должника прямо из операции, кнопка под большой палец и дублирование базы в `IndexedDB`) сразу заработают.
