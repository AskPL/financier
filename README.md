# Финансист 3.0 — Чистый движок & Android 2026 UI

Полностью переписанная с нуля версия приложения без старых костылей и дублирующихся файлов.

## Что изменилось в архитектуре 3.0
- **4 чистых файла вместо 19**:
  - `index.html` — чистая семантическая разметка с нижним меню Material 3 и шторками Bottom Sheet.
  - `styles.css` — единая дизайн-система **Android 2026 / Material 3 Expressive** (тёмная тема OLED Carbon `#090D16` и светлая Cool Alabaster `#F2F5FA`, контрастные бейджи и карточки Bento).
  - `core.js` — единое математическое ядро и мигратор состояния (`migrateState`), 100% совместимый со всеми старыми бэкапами `financier.personal.v1`.
  - `app.js` — единый контроллер экранов и модалок без единого `.replace()` по HTML-строкам.
- **Все фичи 2.0 на месте**:
  - Вкладка **«Доставка»**: выбор налога прямо на старте смены (`0% / 4% / 6%` или свой `%`), 3 крупные кнопки выдач (`1`, `2`, `3+`), `− Расход на смене` и умная сверка с выпиской.
  - **Создание должника прямо внутри операции** (`➕ Новый человек / создать прямо здесь…`) + история операций по каждому должнику.
  - **Родная клавиатура смартфона** с авторасчётом выражений (`250+180` → `430`) и полоской знаков `+ − × ÷ =`.
  - **Быстрый сплит чека** по категориям вместо поштучного ввода товаров.
  - **Локальный авторазбор отчёта** + 1-клик копирование текстовой выписки для любого чата с ИИ.

## Запуск через Simple HTTP Server / Python
```bash
python -m http.server 8080
```
Открой `http://localhost:8080` в браузере (или установи как PWA / собери APK по инструкции в `APK-GUIDE.md`).
